## Description (short — the "what is it")
Vireo is a fast, native macOS markdown editor that hides the syntax **even while
you edit** — no preview pane, no raw `##` or `**`. Bold looks bold, headings look
like headings, and it's still a plain `.md` file on disk. ~4MB, no vaults, no
plugins, no subscription. Free.

## First comment (maker's story — post immediately)

Hey Product Hunt 👋 I'm Mate, I built Vireo.

Every AI tool I use — Claude, Cursor, ChatGPT — writes markdown all day. But every
app I opened it in either showed me the raw `##` and `**`, or wrapped a plain text
file in a 300MB Electron app with a vault and a plugin store just to display it.

So I built the thing I wanted: a native Mac app that shows markdown as a clean
document and hides the syntax *while you're editing it* — not in a separate preview.
The magic is that the syntax never appears on screen, but the file on disk is still
byte-for-byte plain GitHub-Flavored Markdown. Your files stay yours, openable in
anything, forever.

It's Swift on Apple Silicon, about 4MB, opens instantly, and it's completely free —
no account, no subscription, no upsell. Set it as your default `.md` handler and
every markdown file in Finder opens clean (Quick Look even renders in its style
without launching the app).

It's deliberately minimal — no plugins, no AI, no graph view. It does one thing:
makes the markdown you already have readable and editable, fast.

Would genuinely love your feedback, especially on the editing feel. What would make
it your default? (macOS 15+, Apple Silicon — that's the current limitation.)
